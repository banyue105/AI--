# 合并前统一验收表

> 模块负责人自检一次，集成人再复核一次。任何硬性项失败，都不要直接合并。

## 1. 边界与变更

- [ ] 只修改负责模块、必要共享类型和已约定的路由注册点；
- [ ] 没有覆盖其他队友尚未合并的改动；
- [ ] 没有重建 `frontend`、替换技术栈或引入第二套 UI 库；
- [ ] 新依赖确有必要，已记录用途与体积影响；
- [ ] 没有密钥、密码、个人数据、生成缓存或构建产物进入提交。

## 2. 视觉一致性

- [ ] 完整遵守 `plans/00-ui-style-contract.md`；
- [ ] 页面使用现有 token，没有在 Vue 组件或模块样式中新增裸色值；
- [ ] 页头、按钮、输入框、状态、区块标题、弹窗与 `/ability` 一致；
- [ ] 新样式使用模块前缀，没有污染 `.card`、`.title` 等泛化全局选择器；
- [ ] 没有渐变、光球、大圆角、卡片套卡片、营销 hero 或装饰性玻璃；
- [ ] Lucide 图标尺寸和线性风格一致，图标按钮有 `aria-label`/`title`；
- [ ] 状态同时使用文字与颜色，AI 结果带依据、来源或假设。

## 3. 响应式与交互

- [ ] `1280 x 720` 首屏层级清晰，没有过宽文本和错位；
- [ ] `360 x 800` 无页面级横向溢出；
- [ ] 宽图、宽表和路径只在自身容器内滚动；
- [ ] 最长真实中文文案不会遮挡、截断关键操作或撑破容器；
- [ ] 键盘可以访问主要按钮、输入、tab 和弹窗关闭操作；
- [ ] 核心信息不依赖 hover；
- [ ] 加载、空数据、错误、禁用、保存成功和 AI 失败状态完整；
- [ ] 动态内容出现时，按钮和工具栏没有明显跳动。

建议在浏览器控制台执行：

```js
document.documentElement.scrollWidth <= window.innerWidth
```

手机视口必须返回 `true`。

## 4. 数据与接口

- [ ] 页面通过 service 访问 `/api/v1`，组件不直接 `fetch`；
- [ ] 结构化类型与后端 DTO 语义一致；
- [ ] 没有 API Key 或后端暂不可用时，确定性 fallback 能完成演示；
- [ ] mock 位于 service/adapter 层，不散落在 Vue 模板；
- [ ] 写入操作有校验、失败反馈和可恢复路径；
- [ ] AI 不直接生成未经规则校验的精确数值结论。

## 5. 构建与手动流程

- [ ] `npm run build` 通过；
- [ ] 后端相关测试通过，或清楚记录未运行原因；
- [ ] 从首页进入模块、返回首页、刷新页面均正常；
- [ ] 至少完整走通一次“输入 -> 结构化 -> 用户确认 -> 可视化 -> 修改/比较”；
- [ ] 浏览器控制台无新增 error；
- [ ] 接口失败不会使整页白屏。
